GOOGLE APPS SCRIPT · DAILY MEDICAL BLOG AUTOMATION

구글 앱스 스크립트(GAS) 질환별 매일 자동 블로그 발행 시스템

3D 인체모형의 8대 질환(무릎·경추·요추·공진단·자율신경·위장·자궁·전립선)별로 매일 오전 08:00 학술 임상 칼럼이 자동 생성·발행되어 본 3D 모형 페이지에 실시간 반영됩니다.

STEP 01 · 스크립트 복사
GAS 자동발행 코드 붙여넣기
아래 [📋 GAS 전체 코드 복사] 버튼을 눌러 script.google.com 새 프로젝트에 붙여넣습니다.
STEP 02 · 매일 자동 트리거 등록
setupDailyAutoPublishTrigger 실행
함수 목록에서 setupDailyAutoPublishTrigger를 1회 실행하면 매일 오전 8시 8대 질환 칼럼이 자동 발행됩니다.
STEP 03 · 워드프레스 & 웹앱 실시간 연동
워드프레스 REST API + JSON 피드
카페24 워드프레스 질환별 카테고리(blog-knee~blog-prostate)와 GAS 웹앱 URL을 통해 3D 모형에 즉시 표시됩니다.
🔗 구글 앱스 스크립트(GAS) 웹앱 배포 URL 연동 (선택 — 입력 시 워드프레스 REST API와 동시 실시간 병합)
🟢 현재 워드프레스 REST API (/wp-json/wp/v2/posts) 8대 질환 카테고리 실시간 연동이 활성화되어 있습니다.
