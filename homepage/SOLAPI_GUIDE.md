# [바른한의원] 솔라피(SOLAPI) 카카오 알림톡 1만 원 소액 연동 가이드

> **작성자:** 아트 (Art)  
> **장점:** 5만 원 충전 부담 없음! **1회 1만 원(또는 계좌이체 1,000원)**부터 자유 충전 가능.

---

## 1. 솔라피(SOLAPI)의 핵심 혜택

- **최소 충전:** 신용카드 **10,000원**부터 / 가상계좌 **1,000원**부터 가능 (알리고 5만 원 대비 1/5 수준)
- **발송 단가:** 알림톡 1건당 **약 8원~10원** (1만 원 충전 시 약 1,100건 발송 가능)
- **무료 테스트 포인트:** 회원가입 시 무료 체험 크레딧 즉시 지급

---

## 2. 3분 세팅 순서

### 1단계: 솔라피 회원가입 및 충전
1. **[솔라피 웹사이트 (solapi.com)](https://solapi.com)** 접속 및 회원가입
2. 상단 메뉴 ➔ **[충전/관리]** 클릭
3. **10,000원** (또는 원하시는 소액) 카드 결제 또는 가상계좌 입금

### 2단계: 카카오 채널 연동 (PFID 발급)
1. 솔라피 대시보드 ➔ **[카카오 채널]** (또는 발신프로필) 메뉴 이동
2. 바른한의원 카카오 채널 (`@바른한의원`, `_ykxcLK`) 연동 신청
3. 카카오톡 관리자 인증번호 입력 ➔ 발급되는 **PFID** 확인 (예: `PF...`)

### 3단계: 발신번호 등록
1. **[발신번호 관리]** 이동
2. 바른한의원 대표번호 (`042-488-1075`) 통신서비스 이용증명원 또는 ARS 인증으로 등록

### 4단계: 알림톡 템플릿 등록 (Template ID 발급)
1. **[템플릿 관리] ➔ [새 템플릿 등록]** 클릭
2. 템플릿명: `바른한의원_키성장_예약접수안내`
3. 템플릿 내용에 아래 문안 복사·붙여넣기:

```text
[바른한의원] 키성장 클리닉 진료예약 접수 안내

#{보호자명} 님, 바른한의원 키성장·성조숙증 클리닉 진료예약 신청서가 정상적으로 접수되었습니다.

15년 임상경력의 대표원장실에서 남겨주신 사전 진료 차트를 직접 면밀히 검토한 후, 배정 가능한 진료 일정 및 맞춤 상담 안내를 위해 순차적으로 연락을 드립니다.

■ 진료예약 접수 상세 내역
• 접수 번호 : #{예약번호}
• 보호자 성함 : #{보호자명} 님
• 자녀 정보 : #{자녀정보}
• 희망 진료 : #{진료형태}
• 주요 고민 증상 : #{고민증상}
• 접수 일시 : #{접수일시}

※ 긴급 일정 변경 또는 문의 사항은 바른한의원 카카오 채널 1:1 채팅이나 원내 유선(042-488-1075)으로 문의해 주시기 바랍니다.

감사합니다.
바른 마음, 정직한 처방 · 바른한의원
```

4. 버튼 추가:
   - 버튼명: `1:1 카카오톡 상담 바로가기`
   - 링크 타입: `웹링크`
   - 모바일/PC URL: `https://pf.kakao.com/_ykxcLK/chat`
5. 승인 후 생성되는 **템플릿 ID (Template ID)** 확인

### 5단계: API Key 발급
1. 대시보드 ➔ **[API Key 관리] ➔ [새 API Key 생성]**
2. 발급되는 **API Key**와 **API Secret** 복사

---

발급받으신 아래 4가지를 채팅창에 알려주시면, 제가 [wordpress-solapi-endpoint.php]에 즉시 등록하여 실시간 발송을 가동시켜 드립니다:

```text
1. API Key : 
2. API Secret : 
3. 카카오채널 PFID : 
4. 템플릿 ID (Template ID) : 
```
