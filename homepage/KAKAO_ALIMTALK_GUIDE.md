## 1. 개요 및 발송 프로세스

환자가 홈페이지에서 진료예약 신청서를 작성하고 **[진료 신청하기]**를 누르면, 환자가 번거롭게 카톡 채팅창에 붙여넣기를 할 필요 없이 **환자의 카카오톡으로 예약 접수증 알림톡이 1초 만에 자동 발송**되며, 동시에 **대표원장실 휴대전화로도 신규 환자 차트 내역이 자동 수신**됩니다.

```
[환자] 홈페이지에서 진료 예약 신청 클릭
   ↓
[시스템] 카카오 공식 알림톡 API 자동 호출 (건당 약 6.5원~8원)
   ↓
[동시 발송 1] 환자 카카오톡으로 "바른한의원 진료예약 접수증" 알림톡 도착
[동시 발송 2] 대표원장님 스마트폰으로 "신규 환자 상세 차트" 문자/알림톡 도착
[기록 보관] 서버 내 reservations.json 및 관리자 명부에 영구 보관
```

## 2. 추천 알림톡 발송 대행사 (가장 저렴하고 승인이 빠른 곳)

국내에서 가장 널리 사용되며 웹/워드프레스 연동이 간편한 곳은 **알리고(ALIGO)**입니다.

- **사이트:** [알리고 (https://smartsms.aligo.in)](https://smartsms.aligo.in)
- **발송 단가:** 알림톡 건당 **6.5원 ~ 8원** (1,000건 발송 시 약 7,000원 수준으로 극히 저렴)
- **준비물:** 바른한의원 사업자등록증 사본 1부, 카카오 채널 관리자 권한

### 3분 세팅 순서:
1. **알리고 회원가입** 후 [카카오 알림톡] 메뉴 이동
2. **발신 프로필 등록**: 바른한의원 카카오 채널 검색 후 관리자 인증번호 입력 ➔ **발신프로필키(Sender Key)** 자동 발급
3. **템플릿 등록**: 아래 3번 항목의 승인 템플릿 문안을 그대로 복사하여 제출 (영업일 기준 1~2일 내 카카오 본사 승인)
4. **API 키 확인**: 마이페이지 ➔ [API Key 발급]

## 4. 로컬 서버 및 워드프레스 연동 현황

1. **로컬 백엔드 서버 (`serve.js`)**:
   - `POST /api/send-alimtalk` 엔드포인트 완비
   - 예약 발생 시 콘솔 로그 출력 및 `reservations.json`에 환자 차트 자동 영구 저장
   - `GET /api/reservations`로 전체 접수 목록 실시간 조회 가능

2. **워드프레스 및 웹 프론트엔드 (`wordpress-growth.html`, `growth.html`)**:
   - 환자가 제출 시 버튼 로딩 스피너 작동
   - 전송 완료 후 품격 있는 **골드/에메랄드 알림톡 접수증 모달** 자동 노출
   - 환자 전화번호 및 공식 접수번호(`RES-XXXXXXXX`) 실시간 렌더링
   - 카카오톡 1:1 상담창 바로가기 및 유선 전화 원클릭 다이얼 제공
