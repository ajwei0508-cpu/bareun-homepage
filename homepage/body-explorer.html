GOOGLE APPS SCRIPT · 9대 카드 질환별 하루 1편 자동 발행 시스템

구글 앱스 스크립트(GAS) 9대 질환 카드별 매일 1편 자동 블로그 발행 시스템

3D 모션 백과사전의 9대 질환(소아성장/소아비만·경추/탈모·척추/관절·공진단·자율신경/두통/어지럼/실신·소화/담적·대사/복부비만·자궁/난임·전립선/요실금)별로 각각 하루 1편(일 9편)씩 임상 칼럼이 자동 생성·발행되어 본 3D 모션 백과사전에 최신글 3개가 자동 노출 및 내부링크로 연결됩니다.

STEP 01 · 스크립트 복사
GAS 자동발행 코드 붙여넣기
아래 [📋 GAS 전체 코드 복사] 버튼을 눌러 script.google.com 새 프로젝트에 붙여넣습니다.
STEP 02 · 매일 자동 트리거 등록
setupDailyAutoPublishTrigger 실행
함수 목록에서 setupDailyAutoPublishTrigger를 1회 실행하면 매일 오전 8시 9대 카드 질환별 각 1편(일 9편) 칼럼이 자동 발행됩니다.
STEP 03 · 3D 모션 백과사전 최신글 3개 자동 노출
워드프레스 REST API + 내부링크 연결
카페24 워드프레스 9대 질환 카테고리(blog-knee~blog-prostate)와 연동되어 각 질환별 최신글 3개가 자동 노출되고 추천 블로그로 내부링크가 연결됩니다.
🔗 구글 앱스 스크립트(GAS) 웹앱 배포 URL 연동 (선택 — 입력 시 워드프레스 REST API와 동시 실시간 병합)
🟢 현재 워드프레스 REST API (/wp-json/wp/v2/posts) 9대 질환 카테고리 실시간 연동이 활성화되어 있습니다.
