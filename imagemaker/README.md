# ✨ IDENTITY LOCK STUDIO — 원장님 전용 인물 고정 AI 사진관

인물 사진 1장만 첨부할 때 매번 얼굴이 다르게 왜곡되는 문제를 근본 해결하기 위해 제작된 **개인용 초경량 올인원 인물 고정 스튜디오**입니다.

## 핵심 파이프라인 (오차 0% 하이브리드 구조)
1. **1차 골격·두상·안경·체형 생성 (`FLUX Portrait LoRA` / 무학습 `PuLID-FLUX`)**:
   - 실제 사진 15~20장을 1회 학습시켜 만든 전용 `.safetensors` 금형(`fal-ai/flux-lora-portrait-trainer`)을 사용해 어떤 각도와 조명에서도 동일한 두상과 인상을 생성합니다.
   - 학습 전에도 기본 등록된 사진만으로 즉시 무학습 촬영(`fal-ai/flux-pulid`)이 가능합니다.
2. **2차 실제 이목구비 1:1 정밀 고정 (`Face Lock`: `InsightFace` + `CodeFormer`)**:
   - 생성 직후 ★ 대표 얼굴 사진의 눈·코·입 랜드마크를 한 번 더 정밀 매핑(`fal-ai/face-swap`)하고 실제 모공·안경테 해상도를 복원(`fal-ai/codeformer`)하여 이질감을 제거합니다.
3. **기존 홈페이지 이미지 얼굴만 100% 교정**:
   - `바른한의원 홈페이지/homepage` 내 기존 원장님 이미지들을 자동 불러와 배경·가운·손동작은 그대로 보존한 채 얼굴만 실제 원장님 얼굴로 교정 및 자동 백업 교체합니다.

## 실행 방법
- `start-studio.bat` 더블클릭 또는 터미널에서 `node serve.js` 실행 후 `http://localhost:4500` 접속
