# ✨ IDENTITY LOCK STUDIO — 원장님 전용 인물 고정 AI 사진관 (🆓 무료 로컬 GPU & 👑 유료 PRO 품질 비교 에디션)

인물 사진 1장만 첨부할 때 매번 얼굴이 다르게 왜곡되는 문제를 근본 해결하기 위해 제작된 **개인용 초경량 올인원 인물 고정 스튜디오**입니다.

## 🎨 직관적인 색상 구분 체계
- **🆓 초록(에메랄드) 메뉴**: **평생 0원 완전 무료** (HuggingFace ZeroGPU `PuLID-FLUX` + 내 PC 그래픽카드 `GTX 1070 DirectML` 오프라인 5종 ONNX 엔진)
- **👑 금색(골드) 메뉴**: **유료 PRO 클라우드** (`fal.ai` 전용 FLUX Portrait LoRA 학습, 28스텝 클라우드 촬영, 클라우드 `CodeFormer` 복원)
- **⚖️ 에메랄드+골드 듀얼 메뉴**: **동일 조건 [무료 vs 유료 PRO] 1:1 동시 제작 및 품질 비교실**

## ⚖️ 무료 vs 유료 품질 비교실 (`탭 3`)
1. **↔️ 반반 커튼 슬라이더**: 동일한 조건으로 제작된 무료 결과물(좌측)과 유료 PRO 결과물(우측)을 슬라이더로 밀며 눈매·금테 안경·피부결 차이를 직관적으로 확인합니다.
2. **🔍 좌우 나란히 + 2.5배 동시 픽셀 돋보기**: 사진 위에 마우스를 올리거나 `[👁️ 눈매·안경테]`, `[👃 콧대·모공]`, `[👄 입매·턱선]` 버튼을 누르면 양쪽 동일한 얼굴 좌표가 2.5배로 동시에 확대됩니다.
3. **📊 동일 기준 AI 품질 성적표**: 등록된 334장 다각도 기준 사진 대비 **실제 얼굴 일치율(`ArcFace %`)**, **피부 모공·안경 선명도(`Laplacian 점수`)**, **해상도**, **소요 시간·비용**을 객관적으로 계측합니다.
