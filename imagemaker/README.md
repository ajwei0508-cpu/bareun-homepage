# ✨ IDENTITY LOCK STUDIO — 원장님 전용 인물 고정 AI 사진관 (평생 0원 무료 GPU 에디션)

인물 사진 1장만 첨부할 때 매번 얼굴이 다르게 왜곡되는 문제를 근본 해결하기 위해 제작된 **개인용 초경량 올인원 인물 고정 스튜디오**입니다.
카드 등록이나 API 결제 없이 **평생 0원(무료)**으로 무제한 가동되는 하이브리드 엔진이 기본 탑재되어 있습니다.

## 🆓 핵심 100% 무료 파이프라인 (API 키 · 결제 불필요)

1. **Stage 1 — 무료 클라우드 ZeroGPU 상황·구도 촬영 (`@gradio/client`)**
   - `yanze/PuLID-FLUX` (원장님 대표 얼굴 사진을 ZeroGPU에 직접 주입해 두상·체형·안경·85mm 한의원 조명 생성)
   - 혼잡 시 `black-forest-labs/FLUX.1-dev` → `FLUX.1-schnell` → `Pollinations FLUX` 4중 자동 우회 폴백 지원
   - 한글 상황 설명 자동 의학/인물 스튜디오 영문 프롬프트 변환 내장

2. **Stage 2 & 기존 사진 교정 — 내 PC 그래픽카드(`NVIDIA GTX 1070` DirectML) 오프라인 초정밀 안면 고정 (`local_face_engine.py`)**
   - **다중 사진 512차원 평균 얼굴 금형 (`ArcFace w600k_r50`)**: 등록된 여러 장의 원장님 실물 사진에서 512차원 얼굴 특징 벡터를 추출·평균화하여 단일 사진의 조명/각도 편차를 제거합니다 (`유사도 99%+`).
   - **실제 이목구비 1:1 정밀 이식 (`RetinaFace-10G` + `InSwapper-128`)**: 눈매·콧대·입매·턱선을 실제 원장님 골격 비율 그대로 100% 고정합니다.
   - **안경테 · 머리카락 무손실 보호 (`BiSeNet ResNet-34` 19-Class Parsing)**: `class 6`(안경테) 및 앞머리를 픽셀 단위로 마스킹하여 금테/뿔테 안경이 뭉개지거나 이중으로 겹치는 현상을 완벽 차단합니다.
   - **실사 피부 모공 · 눈동자 초고화질 복원 (`GFPGAN v1.4` 512×512)**: 이식 직후 흐릿함 없이 DSLR 원본급 피부결과 선명도를 약 4초 만에 복원합니다.

3. **기존 홈페이지 사진 30장 얼굴만 0원 교정 & 자동 백업 교체**
   - `바른한의원 홈페이지/homepage` 내 기존 원장님 이미지들을 자동 불러와 배경·가운·손동작은 100% 보존한 채 얼굴만 내 PC GPU로 4초 만에 실제 원장님 얼굴로 교정 및 원본 자동 백업 교체(`_backup_director_faces/`)합니다.

*(선택 사항: 우측 상단 `[유료 클라우드 설정]`에서 `fal.ai` 전용 LoRA 학습 모드도 언제든 병행 사용 가능합니다.)*
